# bootcamp-Likes-Assignment---1
Likes Assignment - 1

A simple interactive feature that demonstrates the core fundamentals of dynamic DOM manipulation using vanilla JavaScript, HTML5, and CSS3.

##  Objectives
* Handle user interaction using the JavaScript `onclick` event listener.
* Utilize `document.querySelector()` to target and dynamically update specific HTML elements without reloading the page.

## Features
* **Dynamic Like Counter:** Clicking the "Like" button instantly increments the counter for "Some User" by `1`.
* **Pixel-Perfect Wireframe Design:** Styled with a clean layout and sharp black shadows to match the provided project mockups.

##  Tech Stack
* **HTML5:** Structured the post card components.
* **CSS3:** Managed layout, positioning, and custom retro-style shadows.
* **JavaScript (ES6):** Handled the increment logic and DOM updates.
